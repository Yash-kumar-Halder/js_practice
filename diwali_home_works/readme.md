# Deep equality

# Requirments
  - Write a function isEqual.
  - It will take two argument.
  - It will check two values are equal or not
  - Return a boolean value

  - It must handle different types of data type
  - It must check by value and as well as data type

# Equality
  - Two boolean
  - Two number
  - Two string
  - Two array
  - Two objects

# Unequality
  - Two boolean
  - One boolean and one number
  - One boolean and one string
  - One boolean and one array
  - One boolean and one objects
  
  - Two number
  - One number and one string
  - One number and one array
  - One number and one objects

  - Two string
  - One string and one array
  - One string and one objects

  - Two array
  - One array and one object

  - Two objects
